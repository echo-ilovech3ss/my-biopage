# my corner of the internet

A small personal site for my projects and the things I'm into. It's plain HTML, CSS, and JavaScript on purpose—there is no build step and very little to go wrong.

Live at [shreyasloveschess.netlify.app](https://shreyasloveschess.netlify.app).

## run it

Open `index.html`, or start any static file server from this folder:

```sh
python -m http.server 8000
```

The only external requests are for the two Google Fonts used by the page. Project and profile links go to their respective sites when clicked.

It has an about section, some projects, hobbies and profile links. Nothing complicated.
